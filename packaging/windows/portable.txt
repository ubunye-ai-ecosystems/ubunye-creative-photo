Ubunye Photo portable mode

While this file sits next to photocraft.exe, Ubunye Photo keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the UbunyeCreativePhotoData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move Ubunye Photo with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\org.ubunye.creative.photo) instead.
If UbunyeCreativePhotoData can't be written (for example on a read-only drive), Ubunye Photo says so and
uses %APPDATA%\org.ubunye.creative.photo instead.
